LabRescue · Source guide

Follow one classroom report

LabRescue helps a teacher record a classroom-equipment problem, try authored safe checks, keep the lesson going, and prepare a technician handoff.

This is a source-code reference route, not evidence that a guided code tour has been completed.

Reference route (2–3 code stops)

  1. Start at components/ReportForm.tsx. Follow the form's submit handler: it validates the report before calling the app.
  2. Continue to components/LabRescueApp.tsx. createCase gives the report an ID and timestamps, then asks the persistence helper to save it.
  3. Finish at lib/case-storage.ts, components/Dashboard.tsx, and components/CaseWorkspace.tsx. saveCases writes browser-local data; the dashboard renders open cases from that saved collection. The case workspace also offers technician-confirmed resolution after a successful check, a safety stop, or all checks are complete.

A practice to reuse

For the report journey, the PRD specifies a saved open case and local browser storage. The implementation connects validation, case creation, persistence, and dashboard display. On another project, trace one user action through those points and verify the visible result before expanding the feature.

Evidence: prd.md — Core Journey, lib/case-storage.ts, and the successful npm run lint and npm run build checks in the current workspace.

Run the app

  1. In the repository folder, run npm install.
  2. Run npm run dev and open http://localhost:3000.

Storage note: reports live in this browser on this device; they are not synced or backed up.
